# 通用规范

本目录存放跨会话共用的文档规范。任何角色的会话都可读取；新增与改写只由全局会话执行。

## 结构

一条规范一个子目录，目录名即规范名，例如 `发布流程/`、`文档结构/`。

- 正文放在子目录内，入口文件用 `README.md`；篇幅长时拆成多份，并在入口列出清单。
- 规范自带的脚本与附件放在同一子目录内，不放进 `_Control_Center/tools/`：脚本与正文同生共死，一起搬走才不会失效。
- 规范只写做法、判据与验收条件，不写某一次作业的进度与结果；进度属于交接与台账。

## 查找

用户提到「按某某规范进行」一类要求时，两处都属查找范围：先看本库有无同名规范，再看本目录。两处都有时按本库那份执行，本目录那份作为通用版本。

正文取到后按其中的步骤与判据执行，不自行增删步骤；规范本身需要改动时，先改规范再作业。

## 写入

新增或改写由全局会话执行，项目与杂项会话只读。规范里的路径与工具名要与插件当时的实际口径一致，改名或换入口时同步改本目录。

目录内只有本说明是合法状态：尚无共用规范时，各库按自己的文档执行。
