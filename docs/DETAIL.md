# 插件详情

功能完善的工作流：上下文有压力时压缩并保留要点，任务较重时先写计划。任务或整个项目也可交给外部会话。另提供文件体系参考，以及快照、备份与迁移工具。

## 上下文

- 水位到 35%、50% 时，助手写下目标、已定方案、下一步与易错之处（称为胶囊），再压缩上下文。
- 到强制档时，由插件执行压缩。
- 需要换任时重写交接文档：归档旧交接，写入新正文，由接任会话继续。

## 任务

- 任务较重或涉及多份文件时，先写计划再执行。
- 计划、交接、台账随任务存放，接任者按路径读取。

## 外派

- 单件任务或整个项目可交给 DeepSeek Harness（DSH）之外的会话推进，口径写进给对方的提示词。
- 外部会话交回时按归还流程办理，交接与在任登记不变。

## 边界

- 不改变模型能力，不替代宿主工具。
- 换任须经用户授权，删除须经用户确认。
