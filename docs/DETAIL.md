# 插件详情

本文给评估本插件的使用者概览其功能。上下文有压力时压缩并保留要点，任务较重时先写计划。任务或整个项目也可交给外部会话。另提供文件体系参考，以及快照、备份与迁移工具。

## 任务

- 轻量任务直接执行，不写计划，不做查证。
- 繁重任务先写计划；详略由助手按任务轻重自行判断。
- 任务较大时拆子智能体并行，助手只做统筹与收尾。
- 同一批文件的后续工序交回原处理者，不另开会话。

## 上下文

- 上下文产生压力时，由助手自行决定是否压缩或换任。
- 压缩前，助手先把任务做到合适位置，再收束目标、方案、下一步与易错之处。
- 到达强制线时，由插件执行压缩。
- 换任时重写交接文档，接任会话按交接继续。

## 文件体系

- 为项目提供文件体系参考：任务根存行动计划，任务内按批次留台账。
- 交接文档按全局、项目、杂项分放；换任时一步完成归档、写入与结构体检。
- 快照与备份：库快照带清单，可逐项校验；迁移有打包与恢复。
- 归档与回收：交接、计划与快照按约定目录存放，旧备份与删除物按确认清理。

## 外派

- 单件任务或整个项目可交给 DeepSeek Harness（DSH）之外的会话推进。
- 交出口径写进给对方的提示词；交回时按归还流程办理。
- 暂任期间交接与在任登记不变。

## 边界

- 不改变模型能力，不替代宿主工具。
- 换任须经用户授权，删除须经用户确认。
