# 使用说明

本文给使用者按使用顺序说明本插件的全部流程，与设置页「使用说明」卡片同源。需要对话的流程给一行示例，其余只写操作步骤。

各工具的动作与配置见 [配置参考](reference.md)，安装与版本说明见 [README](../README.md)。

## 一、首次安装

### 一键部署

1. 在设置页输入框填写工作区目录路径。
2. 点击「一键部署」，一次完成建文件体系、注册工作区与新建全局会话。

### 任命已有会话

1. 在「会话角色」卡片把该会话的角色选为「全局」。
2. 点击「设置角色」，再点击「确认设置」。

### 只建文件体系

1. 点击「仅建立文件体系」。
2. 事后再点击「注册为工作区」。

### 补建全局会话

1. 工作区已接入但尚无全局会话时，点击「全局会话」卡片的「创建全局会话」。

## 二、建项目或杂项会话

### 建项目或杂项会话

对全局说：`我需要新建一个项目，叫xxx`

1. 全局确认归属与命名，建出会话。
2. 会话先问清任务的目标、范围与保留要求。
3. 理解后列出任务大纲，请你确认理解是否正确。
4. 确认后给出初步文件体系，请你选择一键建成或先修改。

## 三、日常

### 换任

1. 在设置页「授权」卡片点击「授权重置」，也可在聊天框发送 `/allow-reset`。
2. 授权后在任会话办理换任：写交接、建接任会话、登记在任。

换任后，项目与杂项会话在下一次运行时会收到一行提示。内容为新任全局的名称、session id 与接任时刻，旧 id 声明作废。提示只出现一次。长期未运行的会话在唤醒时同样收到。

唤醒休眠会话用 `peer`（action="send"）。已归档的会话收不到消息：宿主会拦截归档会话的轮次，投递不会到达。需要唤醒时，先用 `ho_sessions`（action="unarchive"）解除归档。

## 四、交接与协作

### 暂任（交给外部会话）

对在任会话说：`我需要把xxx交给外部会话去做，做完再交回来`

1. 范围 2 种。其一，交出 1 段工序，做完交回。其二，交出整个项目，由外部会话自行推进，何时交回由你决定。
2. 在任会话刷新交接，把提示词写入任务库 `Delegation_Prompt.md`。
3. 提示词写清规范、写域、验收判据与归还要求。
4. 回复只给一行索引。在 DeepSeek Harness（DSH）之外的会话环境中新建会话，将索引发给它。它先读齐规定与体系，再开始作业。
5. 暂任期间交出方仍是在任者：不申请换任授权，不建接任会话。

### 归还

对暂任会话说：`走归还流程吧，项目/杂项要归还给在任会话`

1. 法一：暂任会话刷新交接，由在任者读回。
2. 法二：暂任会话刷新交接并写回执；你转交在任者，在任者核对回执与交接一致后收回。
3. 法三：在任者主动收回，通知暂任会话交回。
4. 从 3 种方式中选一种，均以刷新交接为前提；交接的身份字段填暂任者。

### 团队协作

1. 若多个项目或杂项需要协作，选定其中任一会话作为统筹者。
2. 说明需求后，各会话自行组织沟通并产出结果。
3. 统筹者收齐结果，协作限制自动解除。

例一，视频会话做统筹者。对统筹会话说：

```text
我需要为xxx做一个宣传视频，请你与xxx项目合作，进行若干轮对话，让其为你提供所需材料，直到足够你产出宣传视频后进行视频制作。
```

例二，xxx项目做统筹者。对统筹会话说：

```text
我需要为xxx做一个宣传视频，请你与视频会话合作，为视频会话提供其所需的所有材料，让其足够产出宣传视频。
```

## 五、身份

### 切换身份

对全局说：`将xxx项目/杂项身份改为杂项/项目`

1. 路一：对全局说，由全局改该会话的身份；之后进入该会话，首轮会问是否迁移文件体系。
2. 路二：在设置页「会话角色」卡片直接改身份，点击「设置角色」再点击「确认设置」。
3. 确认后按钮变为唤醒，点击与不点击均可；无论是否点击，该会话首轮都会问是否迁移文件体系。
4. 选迁移：按清单搬移文件体系，并改写与登记身份字段；选不迁移：文件零移动，只改身份与登记。
5. 迁移后给出一套文件体系，并问一键建成还是修改。
6. 改名互转同样先问；选迁移则按新名搬移。
7. 误操作后未唤醒且已将身份改回的，不留待确认，也不投递问句。

### 全局任务独立

对全局说：`我需要把xxx独立为项目`

1. 接手会话在首轮问是否迁移文件体系。
2. 不迁移只改身份与登记，文件零移动；迁移则按清单搬移。

### 转普通会话

1. 在设置页「会话角色」卡片把角色选为「普通」，也可由全局改。
2. 点击「设置角色」，再点击「确认设置」；角色与工具收回，注册清除，文件与目录原位保留。

## 六、查询与迁移

### 回读原文

对助手说：`我记得这一点，我之前要求的是xxx，但是你并不是按照xxx这样做的，你查一下`

1. 助手的实现与讨论结论不符时，可以让助手回查原文。
2. 不必指出在哪一段，说清你记得的要求或关键词即可。

### 打包迁移

对全局说：`我需要把xxx打包成迁移包`

1. 逐文件计算 sha256 后打包；恢复时默认只预演，确认后再写入。

## 约定

1. 压缩不可逆：历史会被摘要替换。压缩前先写胶囊，胶囊写清目标、已定方案、下一步与易错点。
2. 暂任不是换任：不申请换任授权、不建接任会话，交出方仍为在任者。
3. 外部暂任会话不属于 DeepSeek Harness（DSH）。它没有插件工具，也没有 `peer`；只有宿主文件工具与宿主子智能体。
4. 团队协作只适用于 DSH 插件会话。
5. 会话身份只能由全局会话或设置页变更；项目与杂项会话无此权限。
6. 同一时刻只允许一个全局会话；已有全局在任时，「会话角色」卡片不出现「全局」选项。
7. 换任须由用户授权：聊天框发送 `/allow-reset`，或在设置页「授权」卡片点击「授权重置」。
8. 注册名一经写入即固定，改名由全局处理。
9. 以上对话示例可按大意使用，不要求逐字相符。
