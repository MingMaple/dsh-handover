# 0.9.14

修三处与新建会话、换任相关的路径与登记问题，均在真机演练中复现后修复。

## 修复

- 新建杂项会话：启动提示词里的交接路径此前按调用者角色推算，杂项被当成全局，指向全局交接文件。现按新会话自身的角色取路径：杂项读 `_Misc/tasks/<任务>/Handover.md`，项目读 `_Project_Meta/<项目>/Handover.md`；杂项没有任务交接时退回杂项任务标准。强制交接路径的配置项只对全局角色生效。
- 在任登记表的工作区一栏改记会话实际所在的工作区，不再记调用者所在的工作区根。
- 杂项换任：接任会话此前落在工作区根，现落回本会话所在的注册工作区。做法是按会话工作目录反查工作区注册表，反查不到时才退回工作区根。
- 换任启动提示词里的「全局 id」改为现任全局会话。此前填入的是发起换任的前任会话，项目与杂项的接任者因此被指向已经退休的会话。

## 测试

冒烟新增三条回归断言：新建杂项会话的启动提示读本任务交接、杂项接任者落回本会话所在的工作区、接任提示的全局 id 为现任全局。

## 升级

先移除旧版本再安装；或替换文件后在插件列表停用再启用。已存在的在任登记表无需改动，工作区一栏在下次登记时自然更新。
