# 1.0.4

**本次修改**：版本号定为 1.0.4（上一发布版 1.0.3）。本版新增全局换任通知：项目与杂项会话在全局换代后收到一行提示。插件标题、介绍与详情页按新定位重写，中英各一份。README 开头按跨会话工作流重述。

## 新增

- 全局换任通知。项目与杂项会话在步骤边界比对全局现任。发现变化时追加一行提示：新任名称、session id 与接任时刻，并声明旧 id 作废。
- 休眠会话唤醒提示。会话的创建时刻早于现任全局接任时刻时，判定为休眠中换代，唤醒第一步即提示。
- 详情页英文版 `docs/DETAIL.en.md`，中文版沿用 `docs/DETAIL.md`。

## 变更

- 插件标题改为「上下文治理 (dsh-handover)」。
- 介绍改为功能罗列：上下文压缩与换任、计划先行、任务外派、整项目移交，共 4 句。
- 详情页去掉配图，改为上下文、任务、外派、边界 4 节文字，并补文件体系、快照备份与迁移工具一段。
- README 开头改为跨会话工作流表述，当前版本同步到 1.0.4。
- `docs/usage.md` 的换任小节补一段通知说明。

## 修复

- 详情页显示空白：构建产物未随仓库重建，宿主读不到 `locale/` 与 `icon` 的导出。构建改为统一产出到安装目录 `Plugins/dsh-handover/dist`。
- 冷会话收不到投递：`peer` 自己调用投递接口，漏掉了「先恢复会话」这一步，消息只进队列不启动轮次。改为统一走 `sendPrompt`，投递前先尝试恢复。
- 归档会话投递后无反应：归档由宿主的归档闸门拦截，轮次会立即以 blocked 结束。`peer` 现在在投递前拦下并提示先解除归档。
- 从未落过状态的旧会话收不到换任提示。插件只能拿自己的落盘时刻当起始时刻，休眠多日的会话就成了新会话。改为取宿主会话 header 的创建时刻与落盘时刻中较早的一个。
