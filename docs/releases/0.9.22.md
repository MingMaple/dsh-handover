# 0.9.22

设置页「会话角色」改为按 DSH 工作区分组，默认全部折叠；已归档会话与目录已不存在的会话不再罗列；卡片下的说明文字一并删去。插件与文档中的比喻性称谓（「血脉」「历代」「退位」等）改为书面说法（「登记」「历史编号」「已交出的会话」），用户可见文案的「点」统一为「点击」，提示段里过时的按钮名「压缩授权」改为「授权压缩」。本说明新增「安装与使用」一节。工具与提示段不变。

## 自 v0.9.14 以来的累计变化

0.9.15 至 0.9.21 均未单独发布，本次一并发布，累计变化如下。

- 工具整合：入口由 24 个降为 14 个（13 个 `ho_*` 与 `peer`），按「一次做一件事」合并；旧工具名不设兼容桩，替代关系见下文与 README「工具整合」。
- 文档定位：`ho_docmap` 提供读、写、查；写入范围由会话已登记的角色决定，只允许对应的在任会话写入；写入前逐条校验路径、覆盖前留 `.bak`、写盘后当场重装提示段；`ho_gate` 增加路径检查。
- 授权提示：用户授权压缩或换任后，目标会话的提示段在下一轮多一行到期时刻与一次性说明；`ho_status` 的 `phase` 与 `brief` 视图给出「授权」一行。
- 交接类文档不设体积上限：只判结构与占位符。
- 通用规范库：`_Control_Center/standards/` 一条规范一个子目录；三档角色段加查找指针；写入分两档（默认写本库，明确「写入通用规范库」一类说法才写共用库）；`ho_workspace(action="scaffold")` 用于补齐既有工作区。
- 设置页：授权卡改名并按在任会话折叠；「待处理」合并进既有卡片；工具清单独立为默认折叠的「工具明细」；会话水位、通知与交接体检统一以 `_Control_Center/records/Office.json` 的在任为准，普通会话不参与；交接体检只查已登记的项目与杂项，并接受有序列表；会话角色按 DSH 工作区分组、默认折叠、已归档与无目录会话不列；迁移卡片不再把保留的旧备份当作待处理；全页文案与注释改为规范书面语。
- 使用说明：逐条按实现核对，起始简报、换任入口、压缩去向、打包格式、会话清点输出、自检项与文档定位权限均按当前输出改写。

## 会话角色

- 分组依据 `~/.dsh/storages/workspace.json`：以工作区的会话归属为准；未登记的会话按 cwd 的真实路径匹配工作区路径（旧根现为链接，取 realpath 后归组）。
- 每个工作区一行摘要，显示标题与会话数；默认收起，点击展开后可见该工作区的会话表。表内仍按全局、项目、杂项、普通排序，同角色按最近活动。卡片下不再保留说明文字。
- 不在任何工作区下的会话归入末组「未归属工作区」，组内显示其 cwd。
- 已归档会话（`workspace.json` 的 `archivedSessionIds`）不列出；会话目录已不存在的老会话（旧树里删掉的项目库等）同样不列出。

## 数据

- 授权列表与会话水位沿用 `Office.json` 的在任口径，同时受上述归档与目录过滤约束。

## 安装与使用

安装并启用插件后，可在设置的 dsh-handover 页面创建或指定全局；页面底部「使用说明」可供参考。后续将在 GitHub 仓库建立「使用说明」文档。

## 升级

替换 `dist/` 后在插件列表停用再启用；浏览器半不热更新，需刷新设置页。本版未改提示段与工具。
