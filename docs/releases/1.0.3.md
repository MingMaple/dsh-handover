# 1.0.3

**本次修改**：版本号定为 1.0.3（上一发布版 1.0.2）。本版把会话身份拆为角色与布局两轴。改身份与改名固定先问后迁。新建、暂任、团队协作与使用说明的口径同步更新。

## 新增

- 会话身份分为角色与布局两轴。角色为全局、项目、杂项、普通；布局为项目、杂项、全局任务。文件体系按布局安置。
- 新建项目或杂项后，新会话先问目标、范围与保留要求。理解后列出任务大纲待确认，再给初步体系。建成方式由用户选择：一键建成或先修改。
- 平级会话工具新增协作能力。`collab` 登记成员与统筹者；`collect` 收取先完成者的结果。协作期间成员不发确认类消息。
- 新增团队协作规范模板与外部暂任规则模板，随工作区体系建立写入 `_Control_Center` 下对应目录。
- 新增使用说明 `docs/usage.md`。分节与示例取自设置页「使用说明」卡片。覆盖首次安装、建项目或杂项、日常、交接与协作、身份、查询与迁移。

## 变更

- 改身份固定先问后迁。选不迁移则文件零移动、原地注册。选迁移先快照再搬移，给出清单并指出需重写身份字段的文件。迁移后再给文件体系，询问建成方式。
- 改名与改身份走同一套先问后迁流程。
- 设置页「会话角色」卡片只留角色、名称、设置角色、确认设置与唤醒；迁移方式选项移除。
- 使用说明卡片改为单列分阶段，去掉引言段。示例注明对谁说；团队协作给场景与 2 个长例。
- 暂任对象改为不在 DeepSeek Harness 内的外部会话。该会话没有插件工具与 `peer`，只有宿主文件工具与宿主子智能体；暂任只交执行权，不交角色。
- 到线文案与换任提示分档改写。整理线只提示；建议线要求先到合适断点再写胶囊压缩。强制线由插件立即压缩。
- 提示段与手册同步新流程：`Runtime_Manual` §8、`Prompt_Templates` §10.2、`Charter` 与 `System` 模板、`Misc_Task_Standard`。
- README 去掉重复的使用说明，改为指向 `docs/usage.md`；配置参考、常见故障处理与升级说明补齐互链。

## 修复

- `ho_sessions` 的 `migrate` 参数此前被强制为 `auto`，设置页的「先问」不生效；改为按传入值透传。
- 改名互转曾直接迁移、跳过询问，并因待确认期间预登记导致名册重名。现改为先问后迁，待确认期间不预登记。选不迁移时更新在任登记。
- 压缩收益误报：压缩刚返回时读到的是压缩前投影，曾据 0.8% 的缩减误判低收益并建议换任。改为读数不足遮蔽量一半时保留待校准，下一处边界重读，重试 8 次后放弃。
- 审计清理：删除 7 个零引用导出符号；补齐 `ho_docmap` 残留导入、路径扫描措辞与 `Runtime_Manual` 工具清单。

## 移除

- 设置页迁移方式下拉选项。
- 使用说明卡片的引言段。
- 改名强制迁移的旧规则。
