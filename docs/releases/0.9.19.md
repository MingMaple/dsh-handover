# 0.9.19

设置页的在任口径扩到三类会话：会话水位列出全局、各项目、各杂项任务的现任各一行，不再只列项目；交接体检补上已登记的杂项任务。普通会话不参与。

## 在任口径

- 唯一依据是工作区里的 `_Control_Center/records/Office.json`：每条血脉（全局、项目、杂项）的现任 `sessionId` 即为在任会话。普通会话不在登记表里，因此不会出现在授权列表、「会话水位」或通知名单中。
- 杂项不另立注册文件：登记表里的杂项血脉已记下任务名、工作区、现任与历代编号，够用。
- 登记表读不到时退化为不过滤，页面不清空。

## 会话水位

- 表列为会话名、短号、类别、水位、状态、活跃、最后活动；类别取自登记表（全局、项目、杂项）。
- 先按在任过滤，再取前若干行；顺序反过来会把低水位的在任会话切掉。
- 「本轮需通知」只列在任且本轮仍活跃的会话；已交出的旧会话即使更活跃也不通知。

## 交接体检

- 全局一行；项目按 `_Project_Meta/Registry.md` 的项目清单逐个查；杂项按登记表的杂项血脉逐个查，表内以「类别」区分。
- 杂项目录按登记名找：先 `_Misc/tasks/<任务>/`，再兼容旧布局 `_Misc/<任务>/`；两处都没有时报「未找到」，不猜近似目录，以免把别的任务的交接算到这条上。
- 登记名与目录名必须一致，否则体检看不到该任务。

## 升级

替换 `dist/` 后在插件列表停用再启用；浏览器半不热更新，需刷新设置页。本版未改提示段与工具。
