# 1.0.5

**本次修改**：设置页页头新增「对齐检查」按钮。点击后唤醒全局在任会话，唤醒词携带插件内置标准文件的绝对路径。全局据此核对各项目与杂项的文件体系，列出须补项，先问补哪些，得到选择才动手。同时新增只读视图 `ho_status(view="align")`，承担全部机械可判项，省下逐个读文件的开销。README 与版本说明补上按钮用法与「什么时候点」的口径。

**状态刷新**：建议。本版新增的口径须写入工作区文件后生效。涉及内置标准文件、对齐视图与「骨架档案与体系注册要对齐」的判据。升级后点击一次「对齐检查」，全局会给出各项目与杂项的须补清单，未获选择不会改动任何文件。

## 新增

- 设置页页头「对齐检查」。没有全局在任会话时只报错，不新建会话。唤醒只在点击时发生，会消耗全局会话的 token。
- `ho_status(view="align")`：一条命令列出机械可判缺项，分 7 组：配置、副本、骨架、注册、约束条、交接、在任登记。只读，不写盘。
- 内置标准文件 `src/templates/Align_Check.md`：检查流程、须补清单、询问口径、token 红线与维护纪律。
- 副本漂移按节标题比对，只报「本体有、副本无」的节，不覆盖工作区的本地化内容。
- 分叉副本识别：会话头 `isSeeded` 为真且日志有继承事件即认定。
- 分叉按工作目录补 `source="fork"` 角色条目。注册可继承，在任不复制。
- 分叉副本对交接只读：`write`、`rotate`、`archive` 一律拒绝并给出处置。

## 变更

- README 的设置页一节补按钮说明，并写明「建议状态刷新」与「无需状态刷新」的用法。
- 版本说明固定写一行「状态刷新」。口径须写入工作区才生效的，写「建议」；纯底层维护的，写「无需」。
- 文档门禁增加 3 条断言。标准文件的版本块不超过 3 个行为版本；须补清单列齐全。当前版本的版本说明必须写「状态刷新」一行。

## 修复

跨平台修正（Linux 实测，DeepSeek Harness（DSH）0.2.1-rc.3 / ext4）：

- 内置 tar 归档器按字符数判断长名，中文名超过 100 字节被截断；改为按 UTF-8 字节数判断。
- 一键部署与补建全局会话后不写 `Office.json`，紧接着点击「对齐检查」会得到 no-global；改为建会话后补登在任。
- 宿主缺 `workspaceRegistry.create` 时换任整单中止；加能力守卫，退化为按 `workspace.json` 找已注册工作区。
- 落位路径匹配无条件小写，Linux 上 `WS` 与 `ws` 被当作同一处；改为按平台折叠。
- 快照指针把 Linux 绝对路径当相对路径拼接，还做小写，前缀重复。改为保留原大小写、按平台折叠比较。
- 迁移助手 3 处 POSIX 缺陷：目录符号链接被拒、`URL.pathname` 百分号编码读不到模板、删除时给目录 `chmod 0o666` 进不去。
- 运行时手册的 shell 文案写死 Windows PowerShell；改为按平台输出 bash/sh 与 locale 口径。
- 杂项会话建会话的权限用子串 `misc` 判断，路径里带 misc 字样的项目会误命中；改为按 `_Misc` 目录段判断。
- 在任登记名匹配无条件小写，Linux 上 `Demo` 与 `demo` 是 2 个目录；改为按平台折叠。
- 盘符路径只认反斜杠，`D:/ws/x.md` 被截成 `/ws/x.md`；正反斜杠都认。
- 事件「同文件重复」统计与 cwd 的 Projects 段识别按平台折叠；Linux 上区分大小写。
- 项目工作区按路径段匹配，不再用小写子串；同时避免 `Demo` 前缀误配 `Demo2`。
- 迁移前的绝对路径扫描补齐 `/srv`、`/data`、`/tmp` 等 Linux 根。
- 7-Zip 探测候选补 `/usr/bin/7zz`。
- `Align_Check.md` 的口语词被语体门禁拦下；改为「开展工作」。

## 边界

- 不写项目库内文件。库内 `RULES.md` 与库结构由对应会话处理，全局只写 `_Control_Center` 与 `_Project_Meta`。
- 不自动覆盖工作区的本地化规则与模板。整份覆盖须单独获准。
- 未获用户选择时不写任何文件。
