# 1.0.2

**本次修改**：版本号定为 1.0.2（上一发布版 1.0.1）。本版修正上下文压缩的判定、切点与读数，并收敛工具面与配置项。

## 变更

- 压缩改为三线制。整理线 35%、建议线 50% 只注入提示，强制线 65% 由插件压缩；3 档均为当前窗口比例，不扣预留输出。
- 助手线取全量范围，压到当前步之前；`fullCompact=false` 时退回尾部策略，强制线保留最近 20 条与 8000 token。
- 压缩前写锚点与微快照，压缩后注入胶囊；助手胶囊正文上限 4000 字，渲染后 4600 字只报告。
- 压缩返回不再即时测量。校准改在下一条步骤边界进行，取宿主投影水位。读数未定时，回执与胶囊写「待下一轮校准」。
- 计数：助手与强制压缩都计，4 次关闭助手入口，6 次为硬上限。

## 工具面

- 收敛为 6 个：`ho_status`、`ho_handover`、`ho_docmap`、`ho_sessions`、`ho_workspace`、`peer`；原文召回并入 `ho_status(view="recall")`。
- `ho_handover` 动作为 `read`、`write`、`rotate`、`archive`、`compact`；`rotate` 一次完成归档、写入与体检。
- 交接结构体检与换任硬闸保留，换任仍按用户授权办理。

## 配置

- 配置键由 35 个降为 33 个，删除 `retainTokens`、`pureWindowRatio` 等未接入项。
- 移除 `budgetMode`、`boundaryCompact`、`backfillMergeMs`、`resumePrompt` 等已废配置；`boundary` 参数不再接受。
- 宿主压缩阈值 0.8 只读观测，插件不改。

## 修复

- 换任登记改原子写，失败不留半条记录；快照写失败只记日志，不阻断压缩。
- 角色装配只认注册文件，未登记会话按普通处理。
- 工具回执限长，超长时截断并提示收窄范围。

## 兼容

- `engines.dsh` 为 `>=0.2.1-rc.2 <0.3.0-0`；旧版本数据经兼容模块接入。
