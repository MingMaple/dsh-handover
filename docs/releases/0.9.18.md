# 0.9.18

设置页重排：授权只列在任会话并按五个一页折叠，会话水位只列在任项目会话，交接体检只查已登记项目；删掉与其他卡片重复的「待处理」，工具清单单独折叠。行为与工具不变。

## 授权

- 卡片标题由「压缩授权」改为「授权」；压缩与换任仍各一组。
- 两组都只列当前在任会话（以 `_Control_Center/records/Office.json` 各血脉的现任为准），不再列已交出的旧会话；超过五个时分页折叠，点「再展开」继续。
- 每个会话一个按钮，写作「授权压缩」「授权换任」；下方仍可直接填会话 id 或 8 位短号。
- 删掉「当前无有效授权。」占位：没有有效授权时该区域不再出现一行空提示；有授权时显示「有授权」并列出剩余秒数。授权被用掉或到期后整行消失，不留「已失效」。

## 只读数据

- 会话水位只列在任项目会话，退位与前任不再出现；「本轮需通知」同样只列在任会话。
- 交接体检的项目取 `_Project_Meta/Registry.md`「项目清单」里登记的项目，不再按 `_Project_Meta/` 下的目录逐个扫描；未登记的旧目录不再进入体检表。清单为空时显示「暂无已登记项目。」
- 插件信息里的「初始化」在无错误时显示「正常」。
- 「会话间通信守卫」改为「最近一次会话间通信判定」，只在确实有过判定时出现。

## 使用说明与工具明细

- 使用说明只留交互方式、常见请求与约定，不再混入工具清单。
- 工具清单单独成卡「工具明细」，默认折叠，不影响日常阅读；条目与 14 个入口一一对应。

## 文字精简

- 删除与其他卡片重复的内容：「待处理」卡的两类提示分别由「通用约束条闸门」与「交接文档体检」直接给出；未接入工作区时的说明并入「首次安装」。
- 首次安装、授权、迁移、会话角色、全局前置提示词各减一句只在解释「为什么」的话，保留会导致误操作的判据（例如切换只改名与建链接、删除旧副本须输入确认词）。
- 页头不再常显数据通道；读取失败时才显示通道与原因。

## 升级

替换 `dist/` 后在插件列表停用再启用；浏览器半不热更新，需刷新设置页。已存在的会话沿用旧提示段文本（本版未改提示段）。
