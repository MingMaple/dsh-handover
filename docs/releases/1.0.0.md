# 1.0.0

**本次修改**：新增 1.0.0 版本说明（首版）。相对 0.9.22，新增两级任务流程与行动计划。同时新增体系注册、全局任务库、身份互转、名称注册、交接固定流程与会话协作。另新增旧体系迁移，路径比较改为按平台处理大小写。

## 新增

- 两级任务流程。层级一为轻量任务，直接执行，不写计划。层级二为繁重任务，先判断纯窗口是否可能超过 40%（不计当前占用）。超过时，写计划即安排拆分子智能体，本会话只做统筹与收尾；未超过时，计划按本会话完成来写。
- 行动计划。任务根新增 `PLAN.md`；`ho_docmap` 新增 `plan` 动作，用于读写计划与归档旧计划。
- 体系注册。每任务一份 `System.md`；全局总注册 `_Control_Center/records/systems.md` 只列各任务体系文件的路径。
- 全局任务库。`ho_sessions` 新增 `task-init`，建立 `_Control_Center/tasks/<任务名>/` 并登记总注册。
- 全局任务独立。`ho_sessions(action="new")` 新增 `from_task`，把全局任务整体独立为项目或杂项会话。体系与文件一并迁入。
- 身份互转。项目与杂项互转默认先做整库快照再移动。`migrate="direct"` 只建新体系，不搬旧文件。
- 名称注册。`ho_office` 新增 `register`；会话首次注册名称，注册后不得自行修改。
- 交接固定流程。`ho_handover` 新增 `new`：先归档旧交接，再新建空白文件写入；`write` 只用于首次创建。模板 `Handover.template.md` 写明读旧交接、归档、读模板、新建写入 4 步。
- 全局任务交接。`ho_handover` 新增 `task` 参数，供全局会话读写全局任务交接。
- 会话协作。`peer` 新增 `wait`、`collect` 与 `collab`，`send` 支持 `wait=true`。协作期间，被交办方不得向交办者或同组成员发送明文消息。插件 `peer` 与 DeepSeek Harness（DSH）的 `send_message` 均经守卫拦截。`collect` 取回全部结果后限制解除。
- 旧体系迁移。`ho_workspace` 新增 `migrate`，并入体系注册并归档旧目录。
- 跨平台。路径比较按平台折叠大小写；7-Zip 探测覆盖 Windows、macOS 与 Linux；迁移助手不依赖外部 shell。
- 模板与规范。新增 `Plan.skeleton.md`、`System.skeleton.md`、`Handover.template.md`、`Delegation_Rules.md`，以及写作规范 W-01 至 W-42 与依据文本。

## 变更

- 提醒线由 32% 单线改为 35% 与 50% 共 2 条。投递方式改为在本会话工具结果末尾追加。
- 判断标准：35% 档完成剩余流程后不超过 45%，50% 档不超过 55%。
- `ho_docmap` 的动作由 read、write、check 扩为 read、write、check、plan。
- 已有交接不得再用 `write` 改写，该动作只用于首次创建。
- 设置页水位文案改为 35% 与 50%，不再出现 32%。
- 提示段按 1.0 重写为 6 节。全局、项目与杂项共用同一份流程文本。并加入子智能体判据与续用纪律一行，细则仍在章程与运行时手册。

## 移除

- 移除 32% 提醒线与 `warnRatio` 配置项。
- 移除文档定位的独立提示段注入路径与简版提示段。流程文本全文进提示段。
