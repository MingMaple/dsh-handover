# 1.0.0

1.0.0 重建任务流程、体系注册与迁移路径；工具入口仍为 14 个。

## 新增

- 两级任务流程：轻量任务直接执行；繁重任务先判断 40% 纯窗口，再写行动计划。
- 后台提醒：35% 与 50% 各注入 1 次，只进系统提示，不生成用户消息。
- 行动计划：任务根新增 `PLAN.md`，新建前归档旧计划，恢复时按先交接、再计划、后执行。
- 体系注册：每任务一份 `System.md`，全局总注册只列路径，写入后热更新。
- 全局任务库：`ho_sessions` 新增 `task-init`，建立任务库并登记总注册。
- 全局任务独立：`ho_sessions` 的 `new` 支持 `from_task`，一并移入并沿用体系。
- 身份互转：项目与杂项互转默认整库快照后移动，可选直接建。
- 名称注册：`ho_office` 新增 `register`，会话首次注册名称后不得自改。
- 暂任与协作：任务库随附暂任规范与交接规范，协作模板另存模板目录。
- 旧体系迁移：`ho_workspace` 新增 `migrate`，并入体系注册并归档旧目录。
- 语体门禁：新增 `style-gate` 与行为测试，纳入仓库门禁清单。
- 写作规范：W-01 至 W-42 随模板分发，提示段只放指针。
- 交接固定流程：模板写明读旧交接、归档、读模板、新建写入 4 步；`ho_handover` 新增 `new`，先归档旧交接再新建空白文件写入。
- 跨平台：路径比较按平台折叠大小写（Windows 与 macOS 折叠，Linux 保留）；7-Zip 探测覆盖 Windows、macOS 与 Linux 的常见位置与 PATH；迁移助手不依赖外部 shell。
- 会话协作：`peer` 新增 `wait`、`collect` 与 `collab`；`send` 支持 `wait=true`。`collab` 注册协作后，被交办方不能向交办者或同组成员发明文消息，插件的 `peer` 与 DSH 自带的 `send_message` 都经守卫拦截；`collect` 取回全部结果后限制自动解除。`collect` 列多个会话，谁先完成先返回，同时完成就一起返回。

## 变更

- 提醒线由 32% 的单线改为 35% 与 50% 共 2 条一次性提醒。
- 判断标准改为 35% 档不超过 45%、50% 档不超过 55%。
- 压缩线为 35%，硬上限为 85%，同一会话最多压缩 3 次。
- 设置页水位文案改为 35% 与 50%，不再出现 32%。
- `ho_docmap` 的动作改为 read、write、check 与 plan。
- 会话角色卡增加确认步骤；已有全局在任时不提供「全局」选项。
- 提示段按 1.0 重写；全局、项目与杂项共用同一份流程文本。
- `ho_handover` 增加 `task` 参数，供全局会话读写全局任务交接。
- `ho_handover` 的 `write` 只用于首次创建；已有交接时拒绝改写并指向 `new` 与 `append`。
- `ho_gate` 与 `ho_status` 增加旧文档定位的待迁移提示。

## 修复

- 修复会话角色卡在已有全局在任时仍可选择「全局」的问题。
- 修复项目与杂项互转后名册仍保留旧类别的问题。
- 修复身份互转后骨架档案的库根字段未更新的问题。
- 修复注册与计划写入后提示段未重装导致的显示滞后。
- 修复插件重载后在任会话不补注册 35% 与 50% 提醒段的问题；角色提示段文本仍须重启 DSH 或新开会话才换。
- 修复换任时按会话 cwd 匹配工作区只比字符串的问题；旧 junction 路径经 realpath 后也能落到已注册工作区。

## 移除

- 移除 32% 提醒线与 `warnRatio` 配置。
- 移除文档定位的独立提示段注入路径。
- 移除简版提示段，流程规范全文进提示段。

## 安全

- 交接整篇重写前先归档旧交接；首次创建与追加写入前备份。
- 体系注册只接受工作区相对路径，拒绝越界与不存在的路径。
- 身份互转默认先做整库快照，快照落在备份目录。
- 压缩与换任须用户点击授权，单次授权 5 分钟内有效。
- 旧体系迁移不删除旧目录，保留可回退的备份。
- 身份互转改登记前备份 `Office.json`。
