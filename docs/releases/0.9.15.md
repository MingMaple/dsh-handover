# 0.9.15

工具按「会话一次要做的一件事」合并，入口从 24 个降到 14 个；新增文档定位 map 与授权提示行；交接类文档改为只判结构、不设体积上限。

## 工具整合

| 合并前 | 合并后 |
|---|---|
| phase、brief、diag、drift、tokens 五个只读入口 | `ho_status`，`view` 分流 |
| 快照与迁移包两个入口 | `ho_backup`，`action` 取 `snapshot`、`check`、`pack`、`verify`、`restore` |
| 首次建立文件体系 | `ho_workspace(action="init")` |
| 平级会话的六个入口 | `peer`，`action` 取 `list`、`status`、`send`、`peek`、`rename`、`new` |

合并依据：实测 309 个会话日志、31,175 次工具调用，插件工具占 428 次（1.4%），其中四个入口零调用；入口数与每轮 schema 是固定开销。旧入口不再注册，调用会得到未知工具的报错，按上表改用新入口。动作级权限未变：`peer` 的 `list`、`peek`、`rename` 仅全局可用，`send` 与 `status` 各角色可用，`new` 仅全局可用、杂项可建到 `_Misc` 下。

## 文档定位 map

`ho_docmap` 为每个血脉（全局、每个项目、每个杂项任务）各存一份 map，位于 `_Control_Center/records/docmap/`，三列为路径、一句话介绍、什么时候该读。

- 注入该血脉会话的角色提示段；只指路，读不读由会话自己判断；空 map 不注入；不设字数上限。
- 血脉由会话已登记的角色推导，不接受传入项目名；只有该血脉在任者能写（以 `_Control_Center/records/Office.json` 为准），已交出的旧会话只读；全局不代写项目与杂项的 map。
- 写入逐条校验路径存在，缺项整条拒绝并列出；覆盖前留 `.bak`；写盘后当场重装提示段。
- `ho_gate` 增加 map 路径存在性检查。

## 授权提示行

- 用户授权压缩或换任后，目标会话的提示段在下一轮多一行「用户已授权…至…（一次性，用后失效）」，到期或用掉后消失，无授权不占位；两种授权可并存。
- `ho_status(view="phase")` 与 `view="brief"` 的输出新增「授权」一行，给出剩余分钟与到期时刻。

## 接口口径

- 交接类文档不设体积上限：不规定字节、行数、页数，体积由结构与归档重写流程控制。
- 交接体检删去「正在做的事内容过短」的字数下限，只判空节。

## 测试

六道门禁全过：构建、自测、空白冒烟、空白 DSH 验收、迁移端到端、文档检查。冒烟新增四类断言：文档定位的在任者写入权限、路径不存在整条拒绝、空 map 不注入、授权行出现与用掉后消失。

## 升级

先移除旧版本再安装；或替换文件后在插件列表停用再启用。旧入口不再可用，按上表迁移调用点。插件重载后已存在的会话沿用旧提示段文本，需要新文本时重启 DSH。
