# 0.9.20

设置页提示口径与措辞整理。迁移卡片不再把保留下来的旧备份当作待处理；会话角色按全局、项目、杂项、普通排序；全页文案与代码注释统一为简明书面语，「旧副本」改称「旧备份」。工具与提示段不变。

## 迁移卡片

- 待处理判定只看会妨碍使用的情形：原路径缺失或链接悬空、已复制待切换、校验有差异、DSH 登记仍指向旧路径。旧备份保留不算待处理。
- 迁移完成后的状态行会注明「旧备份保留，不影响使用」；删除入口仍在展开区内，删与不删由使用者决定。
- 文案：切换完成后的说明改为「原路径为指向新位置的链接；若已删除，可用「重建链接」恢复」；旧备份一节注明保留不影响使用、删除后无法恢复。
- 「搬迁」统一改为「迁移」（`ho_workspace` 的 `move-status` 输出同改），「旧副本」统一改为「旧备份」。

## 会话角色

- 表格与下拉均按全局、项目、杂项、普通排序；同一角色内按最近活动排序。
- 说明改为陈述句：「点击「设置角色」后当场生效；按钮转为「通知该会话」后，再次点击会投递整理指令并唤醒该会话一轮。」

## 措辞与注释

- 全页「点」改「点击」，示例句与提示句改为书面语（例如「填写绝对路径：全局根 _Workspace 将建在该目录下」「输入「删除」后重试」）。
- 保存全局前置提示词的回执不再提「位置在工具说明之前」，只报字符数。
- 会话间通信判定的「依据」由内部键值改为中文表述：全局角色、向现任全局报告、会话之间直接通信（A → B）、directPeer=off 时的限制。
- 页内注释同步整理：与超时竞速、快照缓存、排序原则等说明改为陈述句，不再用口语化比喻。

## 升级

替换 `dist/` 后在插件列表停用再启用；浏览器半不热更新，需刷新设置页。本版未改提示段与工具。

## 测试

冒烟新增三条结构断言：保留的旧备份不得计入待处理、迁移完成后注明「旧备份保留，不影响使用」、角色下拉顺序为全局、项目、杂项、普通。六道门禁全绿。
