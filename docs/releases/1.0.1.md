# 1.0.1

**本次修改**：新增 1.0.1 版本说明（首版）。行动计划改为固定写入流程，并加入模板节次校验。

## 新增

- 计划模板校验。`ho_docmap(action="plan", mode="write")` 按模板 5 节（目标、步骤、验收、风险、状态）逐节校验，缺节即拒收并列出缺失节次，提示先读模板。
- 计划写入固定流程：先读模板 `_Control_Center/templates/Plan.skeleton.md`，再把上一份计划归档到任务根 `_archive/`，然后新建空白 `PLAN.md` 按节次写入；归档后不读旧计划，也不在旧计划上改写。
- 任务收尾归档：任务结束或换任时把当前计划归档到任务根 `_archive/`，并从体系注册删除「计划」一行。

## 变更

- 模板 `Plan.skeleton.md`、运行时手册 §6、杂项任务标准、章程骨架与设置页使用说明同步固定流程与「不读旧计划」口径。
