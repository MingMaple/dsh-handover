# 1.1.0

## 新增

- 新增 `ho_recall`：按指针回读压缩前原文。支持字面与正则、分词 BM25、结构过滤三路召回，并以倒数排名融合；命中给 `seq` 指针、前后三行与所属段。
- 新增微快照：从会话事件抽取目标、已确认事实、未决、下一步、指针、时刻 6 项；缺项写「未核，待确认」。快照存本机状态目录，原文仍在会话日志。
- 新增段索引：从 `compaction/summary` 事件派生每段序号、遮蔽事件范围、token 数与一行标签；不落盘，可从日志重建。
- 新增压缩后回填：每次压缩至多投一条可见消息。该消息含快照路径、交接路径、段索引与检索提示。5 分钟内连续压缩合并为一条。
- 新增可选旁路语义摘要：默认关闭。开启后仅在里程碑、异常线、同错重复 3 类事件各调用一次，失败静默回退代码抽取。
- 新增提示段行为纪律 4 条。交接只写在途与指针，篇幅以结构控制为主，并约定单份不超 500 行。事件级微快照由插件自动写，只有上下文重置才写全量交接（读旧、归档、读模板、新建）。回填后照交接续跑，不复述。按判据不按固定水位；输出被截断时按提示续读。
- 配置参考新增可直接复制的工具输出裁剪配方（宿主长输出修剪组件）。该配方写在 preset 的 cordis 配置中，本插件不改用户预设。
- 新增工具输出上限与定向放行。`ho_handover` 读支持 `offset`/`limit`，全量读超过 600 行才截断并回报总行数。`ho_docmap` 与 `ho_status` 上限 300 行。`ho_recall` 命中数被截断时给出提示。
- 新增文档一节「与官方预设的关系」：插件不读预设、不按预设分支，只经官方扩缝注入。换预设不改变判据、快照、交接与回填流程。

## 变更

- 上下文维护改为 3 层。宿主做日常摘要；插件做微快照、判据、回填与检索。宏观重置由在任助手写全量交接后原地压缩，不新建会话。
- 后台提醒由固定水位改为异常线：水位比宿主阈值高 25 点，或连续 2 次压缩后水位不回落。该提醒一次性尾注入，不生成用户消息。
- 宏观重置改为 4 条判据。前 3 条为：累计遮蔽不少于 2 倍窗口；压缩增量比低于 0.5；同错或同文件重复不少于 2 次。第 4 条为里程碑或用户要求。
- `ho_status` 的 `phase` 视图增加段索引、快照数、最近压缩时刻、压缩后回落与判据取值。
- `ho_handover(action="checkpoint")` 先落微快照再登记压缩；提示与状态不再显示压缩额度。
- 续跑文案去掉次数上限占位；压缩后第一条消息改为回填消息。

## 修复

- 修复压缩后连续多次投递导致重复唤醒的风险：5 分钟内的后一次压缩只记合并，不再投消息。
- 修复检索命中片段可能从事件首行开始、看不到匹配位置的问题：命中位置按查询回填。
- 修复身份互转的目录错位。项目转杂项时，库内容移入任务目录本身，不再多套一层 `<项目>库`。杂项转项目时，交接、体系与档案归位到 `_Project_Meta/<项目>/`，不再留在库根。来回转换不会层层嵌套。
- 修复 `peer(action="status")` 的预警区判定写死 32% 的问题：改为按宿主摘要阈值（默认 25%）判断。
- 文案统一：提示段、模板、工具说明与返回、错误消息、设置页文案按写作规范改写。错误消息统一为现象、原因、处置 3 段，界面动作统一为「点击」，序列号统一为（1）（2）（3）。
- 变更口径：交接篇幅有 2 种约束并存。结构控制为主，只写在途与指针，不规定字节与页数。另约定单份全文不超过 500 行；超限先删过期内容，不删在途信息。读取端另设 600 行安全网，并可定向放行。

## 移除

- 移除 35% 与 50% 2 档固定提醒，以及对应的一次性提醒状态。
- 移除「压缩 3 次即换任」与 `maxCompactions` 额度判定；换任只在用户明确要求时办理。
- 移除提示段与文档中的固定水位判断标准。

## 安全

- 正则召回拒绝超长模式与明显可回溯的嵌套量词，单次检索设条数上限。
- 检索索引只在内存构建，不落盘；语料与快照都不进入发布包。
- 插件仍不写会话事件；回填只经 `sendPrompt(..., 'queue')` 一条消息。
